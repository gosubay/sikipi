How to play Si Ki Pi

Singapore CNY house rules

Split four cards

You and the banker each get four cards from a standard 52-card deck.

Rank the two-card hands

Strongest to weakest

  1. PairsA-A is highest, then K-K down to 2-2.
  2. 2–8 GongBeats 9 points. Scores 0 with Gong off.
  3. 0–9 pointsAdd the card values and keep the last digit.

A = 1, 2–9 = face value, 10/J/Q/K = 0. Suits have no effect.

Compare rows with the banker

Weak plays weak. Strong plays strong.

  • +1 Win both
  • 0 Win one, lose one
  • −1 Lose both

By default, the banker takes any tied row. With Round pushes selected, a tie on either row makes the round worth 0.
